# Support

## Start here

- Read the [README](README.md) for installation, compatibility, behavior, and troubleshooting.
- Check the [open issues](https://github.com/tejaswin-amara/klu-erp-autofill/issues) for known problems.
- Check the [Chrome Extensions documentation](https://developer.chrome.com/docs/extensions/) for general Manifest V3 and unpacked-extension guidance.

## Report a reproducible problem

If the issue is not already reported, open a [GitHub issue](https://github.com/tejaswin-amara/klu-erp-autofill/issues/new) with:

- Chrome version and operating system.
- Repository version or commit.
- Expected behavior and actual behavior.
- Minimal steps to reproduce.
- Relevant sanitized error messages from the browser console.

Do not include passwords, cookies, session identifiers, student IDs, personal records, or screenshots of a real authenticated account. Remove sensitive values from logs before sharing them.

## CAPTCHA recognition limitations

Recognition is probabilistic and may fail when the CAPTCHA format changes, the image is unavailable, or the model cannot load. Verify the result before proceeding and use the portal's supported manual workflow when needed. This project does not guarantee successful recognition or ERP availability.

## Security reports

Do not report exploitable vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) instead.

## Scope

This is a community-maintained project, not an official KL University support channel. For account access, enrollment, grades, or portal outages, contact the university through its official support channels.
