# KLU ERP Assistant v2.0.0 release artifact

- `klu-erp-assistant-v2.0.0.zip` — runtime package for Chrome's **Load unpacked** flow after extraction.
- `klu-erp-assistant-v2.0.0.sha256` — SHA-256 checksum for the runtime ZIP.

Verify from this directory with a SHA-256 utility appropriate for your operating system. The runtime ZIP intentionally excludes tests, build scripts, and repository-only documentation; those remain at the repository root.

Interactive Chrome verification is still required before treating the build as production-validated. See `FINAL_ENGINEERING_REPORT.md` and `docs/testing.md`.
