# Code of Conduct

## Our standard

We aim to keep participation in KLU ERP Auto-Fill respectful, constructive, and focused on improving the project. Contributors are expected to be considerate of differing experience levels and viewpoints, communicate clearly, and accept good-faith technical feedback.

Examples of unacceptable behavior include harassment, discrimination, personal attacks, threats, doxxing, publishing private information without consent, and deliberately disruptive conduct.

## Project-specific expectations

- Do not post student credentials, session cookies, CAPTCHA images tied to real accounts, or other sensitive personal data.
- Do not use project discussions to coordinate unauthorized access, impersonation, or attempts to defeat institutional security controls.
- Discuss technical disagreements respectfully and focus on evidence, impact, and maintainability.
- Report security issues privately rather than publishing exploit details in public issues.

## Maintainer responsibilities

Project maintainers may edit, reject, or remove contributions and may close discussions that violate this code of conduct or create material security or privacy risks. Enforcement decisions should be proportionate to the behavior and its impact.

## Reporting

For conduct concerns, contact the repository maintainer through the contact options available on the [GitHub profile](https://github.com/tejaswin-amara) or use GitHub's private reporting mechanisms where available. Include relevant context without sharing unnecessary personal or sensitive information.

Reports will be reviewed as reasonably as possible. Please do not use public issue comments for private complaints.

## Scope

This code applies to repository issues, pull requests, discussions, and other project spaces when a person is representing or participating in the project.
